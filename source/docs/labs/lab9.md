# Отчет о лабораторной работе

---

## 1. Что было сделано в работе?
В ходе работы был проведен полный цикл разведочного анализа данных (EDA) датасета об успеваемости 1000 студентов:
* Проведена первичная проверка данных (пропущенных значений не обнаружено).
* Выполнена предобработка: названия столбцов приведены к стандарту `snake_case` (например, `test preparation course` переименован в `test_prep`, удалены косые черты и пробелы).
* Добавлен новый комплексный признак `average_score` — средний балл по трем дисциплинам.
* Выполнена группировка и статистическое агрегирование данных по различным демографическим и социальным категориям.
* Построено 5 аналитических графиков (гистограмма, столбчатые диаграммы, диаграмма рассеяния, boxplot).
* Настроен CI/CD пайплайн для автоматического выполнения ноутбука и генерации HTML-отчета с сохранением результатов в отдельную ветку `reports`.

## 2. Какие библиотеки и методы были использованы?
Для выполнения работы применялся стандартный стек для анализа данных:
* **`pandas`** — для манипуляций с данными. Использовались методы загрузки (`read_csv`), анализа структуры (`info`, `dtypes`, `isnull`), переименования (`rename`), агрегации (`groupby`, `mean`) и описательной статистики (`describe`).
* **`matplotlib.pyplot`** — для визуализации. Применялись функции построения гистограмм (`hist`), столбчатых диаграмм (`plot(kind='bar')`), диаграмм рассеяния (`scatter`) и ящиков с усами (`boxplot`), а также методы оформления (названия осей, заголовки, отключение автоматических подзаголовков).
* **Утилиты `jupyter` и `nbconvert`** (в CI/CD) — для автоматического исполнения кода и экспорта отчета в HTML.

## 3. Какие закономерности удалось заметить?
На основе проведенного анализа выявлены следующие факторы, влияющие на успеваемость:
* **Подготовка:** Студенты, прошедшие подготовительные курсы, показывают средний балл (72.67) значительно выше тех, кто их не проходил (65.04).
* **Питание и статус:** Стандартный обед коррелирует с более высокими (70.84) и стабильными оценками (меньший разброс на boxplot), чем льготное/бесплатное питание (62.20).
* **Пол:** Девушки в среднем учатся лучше (69.57) по сравнению с юношами (65.84).
* **Этническая группа:** Наблюдается ступенчатый рост медианы успеваемости от "Group A" к "Group E".
* **Взаимосвязь предметов:** Выявлена сильная прямая линейная зависимость между баллами по математике и чтению. Основная масса результатов распределена в интервале 40–100 баллов с разбросом около 20 единиц.

## 4. Какие трудности возникли в процессе выполнения?
* **Предобработка строк:** Изначальные названия столбцов содержали пробелы и спецсимволы, что мешало обращению к признакам. Проблема решена массовым переименованием столбцов с помощью строковых методов `pandas`.
* **Оформление визуализаций:** При построении `boxplot` встроенными методами `pandas` появлялись дублирующиеся автоматические подзаголовки. Это потребовало тонкой настройки через `plt.suptitle('')` для аккуратного внешнего вида.
* **Автоматизация CI/CD:** Потребовалось адаптировать конфигурацию пайплайна не просто для создания файлов-пустышек, а для реального запуска кода. Были внедрены команды Git для настройки коммитов от имени бота и автоматического сохранения сгенерированных отчетов (`executed_lab.ipynb` и `report.html`) в отдельную ветку `reports` с использованием флага `[skip ci]`, чтобы избежать зацикливания сборки.
