### Структура собираемых данных

Скрипт был расширен по сравнению с базовым заданием и собирает подробную информацию по каждой статье. В итоговый набор вошли следующие поля:

* **Идентификатор новости** (извлекается напрямую из URL-адреса).
* **Название новости** (заголовок статьи).
* **Дата её размещения**.
* **URL на страницу с конкретной новостью**.
* **Количество просмотров**.
* **Текст** (полный текст статьи, очищенный от HTML-тегов, собирающий абзацы `<p>` и цитаты `<blockquote>`).
* **Теги** (массив категорий, к которым привязана новость).

---

### Описание алгоритма работы

1. **Инициализация:** Задаются базовый URL для обхода (`https://news.itmo.ru/ru/main_news/`) и параметры цикла обхода страниц с лентой новостей.
2. **Сбор ссылок:** Скрипт последовательно запрашивает страницы ленты новостей, парсит HTML и находит ссылки на все публикации в текущем списке.
3. **Глубокий парсинг:** По каждой найденной ссылке выполняется отдельный переход. С помощью BeautifulSoup извлекаются все необходимые метаданные и основной текст публикации.
4. **Логирование процесса:** Для контроля исполнения скрипт выводит в консоль подробное содержимое первых 10 новостей, а затем печатает статус обработки каждые 20 новостей.
5. **Сохранение:** После завершения цикла все собранные данные в виде списка словарей корректно записываются в файл `my_scraped_news_data.csv`.
6. **Интеграция:** В финальной ячейке выполняется монтирование Google Диска (`drive.mount`) для сохранения полученного файла в облачное хранилище.
