# Отчет о разработке автоматизированного парсера новостей логистики

**Цель проекта:** Создание полностью автономного сервиса для сбора, интеллектуальной фильтрации и суммаризации профильных новостей логистики с последующей отправкой готового дайджеста в рабочий чат Telegram.

---

### 🛠 Технический стек и инфраструктура

* **Язык программирования:** Python 3.10
* **Среда выполнения (Хостинг):** Серверы GitHub Actions (бесплатные облачные вычисления)
* **Искусственный интеллект:** Google GenAI (модель Gemini)
* **Интеграция:** Telegram Bot API
* **Ключевые библиотеки:** `requests` (для API), `feedparser` (для чтения лент), `google-genai` (для нейросети).

---

### ⚙️ Реализованный функционал

1. **Сбор данных (Парсинг источников):**
* Настроено чтение RSS-лент с нескольких ведущих отраслевых порталов.


2. **Интеллектуальная фильтрация (AI-модерация):**
* **Жесткие исключения:** Скрипт отсеивает любые новости по заданным исключениям
* **Приоритеты:** ИИ обучен отбирать новости с фокусом на заданных приоритетах.


3. **Форматирование дайджеста:**
* Установлен строгий лимит — **не более 11 новостей** в одной подборке.
* Внедрен лаконичный дизайн для удобного чтения с мобильных устройств: ИИ оставляет только суть (заголовок новости), убирая длинные описания.
* Ссылки на первоисточники элегантно скрыты внутри текста заголовка с помощью HTML-разметки.


4. **Доставка целевой аудитории:**
* Бот интегрирован в групповой чат Telegram. Сообщения приходят напрямую всей команде, минуя личные переписки.


5. **Полная автоматизация (Расписание):**
* Настроен `cron`-таймер. Проект работает автономно, серверы запускаются строго по **четвергам и пятницам в 06:37** по московскому времени. Локальный компьютер для работы парсера больше не нужен.



---

### 🚧 Решенные технические задачи в ходе настройки

В процессе развертывания проекта были успешно преодолены следующие препятствия:

* **Интеграция Git и GitHub:** Решена проблема блокировки доступа (`Permission denied`) при отправке кода за счет создания токена безопасности (Personal Access Token) с правами на управление конфигурациями (`workflow`).
* **Настройка CI/CD (GitHub Actions):** Устранены ошибки невидимости скрипта из-за строгих требований к синтаксису YAML и путям к папкам (`.github/workflows`).
* **Безопасность данных:** Реализована защита конфиденциальной информации. Все ключи от API и токены вынесены из открытого кода в зашифрованное хранилище **GitHub Secrets**.
* **Отладка Telegram API:** Решена проблема скрытых сообщений. Дайджесты адаптированы под требования платформы, настроена отправка в группы (с использованием правильного отрицательного `Chat ID`).
* **Отказоустойчивость:** Внедрена система защиты от перегрузок серверов нейросети (ошибки 429 и 503). Если ИИ-сервер недоступен, скрипт автоматически уходит в спящий режим на 15 секунд и повторяет попытку, предотвращая аварийное завершение программы.
