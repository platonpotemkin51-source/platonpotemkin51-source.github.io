#### Лабораторная работа №4

!!! success "Классификация с применением Scikit-Learn"

    **Тема:** Разработка системы предиктивного кредитного скоринга и оценки риска дефолта.
    
    **📝 Описание:**
    Проект посвящен созданию модели машинного обучения для автоматического предсказания вероятности возврата кредита банковскими клиентами на основе их исторических и демографических данных. В ходе работы был проведен полный цикл подготовки данных, включая разведочный анализ (EDA), обработку пропусков и кодирование категориальных признаков. Для поиска оптимального решения были обучены, настроены с помощью кросс-валидации и сравнены между собой несколько алгоритмов: от базовых kNN и логистической регрессии до ансамблевых методов (Random Forest, Gradient Boosting). Итоговая оценка качества классификации производилась с использованием матриц ошибок и метрики ROC-AUC, после чего была спроектирована архитектура развертывания финальной модели в виде REST API веб-сервиса.

    **Стек:** `Python`, `Scikit-Learn`, `Pandas`, `NumPy`, `Jupyter Notebook`, `Logistic Regression`, `RandomForest`, `SVM`, `kNN`, `K-Fold Cross-Validation`, `ROC-AUC`

#### Лабораторная работа №5

!!! success "Регрессия с применением Scikit-Learn и XGBoost"

    **Тема:** Разработка системы прогнозирования стоимости недвижимости с применением алгоритмов машинного обучения.
    
    **📝 Описание:**
    Проект посвящен созданию регрессионной модели для автоматической оценки стоимости жилья в округе Кинг (США) на основе исторических данных о продажах и характеристиках объектов (площадь, геолокация, оценка риелтора и др.). В ходе работы был проведен полный цикл Data Mining: предварительная обработка данных, анализ значимости признаков (Feature Importance) и фильтрация неинформативного шума. Для поиска оптимального решения были обучены и сравнены между собой несколько алгоритмов машинного обучения: Линейная регрессия, Случайный лес (Random Forest) и Градиентный бустинг (XGBoost). Был произведен автоматический подбор гиперпараметров с помощью GridSearchCV на основе кросс-валидации. Оценка качества моделей производилась по метрикам MAE и RMSE. В завершение была спроектирована архитектура развертывания финальной модели в виде REST API веб-сервиса с помощью фреймворка FastAPI.

    **Стек:** `Python`, `Scikit-Learn`, `XGBoost`, `Pandas`, `NumPy`, `Jupyter Notebook`, `Linear Regression`, `RandomForestRegressor`, `GridSearchCV`, `FastAPI`, `MAE / RMSE`

#### Лабораторная работа №6

!!! success "Предобработка данных и EDA с применением Pandas"

    **Тема:** Предобработка и первичный анализ данных (на примере датасета Titanic).
    
    **📝 Описание:**
    Проект посвящен освоению методов подготовки "сырых" данных к анализу и машинному обучению на классическом наборе данных пассажиров Титаника. В ходе работы был проведен полный цикл предобработки: первичный разведочный анализ (EDA), оценка и заполнение пропусков (медианой, модой и константами), а также преобразование типов. Особое внимание уделено генерации новых признаков (Feature Engineering), таких как социальный статус (титулы) и размер семьи, и обработке выбросов с использованием метода Winsorization (ограничение по 95-му перцентилю). В завершение выполнена агрегация данных и визуализация матрицы корреляций, что позволило выявить ключевые факторы выживаемости на борту.
    
    **Стек:** `Python`, `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`, `Jupyter Notebook`, `EDA`
