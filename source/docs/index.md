    **Тема:** Реализация автоматического деплоя статического сайта с использованием нескольких удаленных Git-репозиториев.

#### Лабораторная работа №4

!!! success "Классификация с применением Scikit-Learn"

    **Тема:** Разработка системы предиктивного кредитного скоринга и оценки риска дефолта.
    
    **📝 Описание:**
    Проект посвящен созданию модели машинного обучения для автоматического предсказания вероятности возврата кредита банковскими клиентами на основе их исторических и демографических данных. В ходе работы был проведен полный цикл подготовки данных, включая разведочный анализ (EDA), обработку пропусков и кодирование категориальных признаков. Для поиска оптимального решения были обучены, настроены с помощью кросс-валидации и сравнены между собой несколько алгоритмов: от базовых kNN и логистической регрессии до ансамблевых методов (Random Forest, Gradient Boosting). Итоговая оценка качества классификации производилась с использованием матриц ошибок и метрики ROC-AUC, после чего была спроектирована архитектура развертывания финальной модели в виде REST API веб-сервиса.

    **Стек:** `Python`, `Scikit-Learn`, `Pandas`. `NumPy`, `Jupyter Notebook`, `Logistic Regression`, `RandomForest`, `SVM`, `kNN`, `K-Fold Cross-Validation`, `ROC-AUC`
