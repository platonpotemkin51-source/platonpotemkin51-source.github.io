    Анализ и визуализация данных об успеваемости

    Тема: Обработка, анализ и визуализация данных об успеваемости студентов с использованием pandas и matplotlib.
    📝 Описание: Проведение полного цикла разведочного анализа данных (EDA) на основе датасета об успеваемости 1000 студентов. Работа включает загрузку и предобработку датасета, очистку данных, создание новых метрических признаков и статистическую агрегацию. Выполнено построение 5 аналитических графиков для выявления социально-демографических закономерностей. Настроен CI/CD пайплайн для автоматического исполнения кода и генерации HTML-отчета.

    Стек: Python, pandas, matplotlib, Jupyter, CI/CD

    Контроль склада

    WoodFlow

    Тема: Разработка комплексных веб-приложений и автоматизация бизнес-логики с использованием фреймворка Flask и SQLAlchemy ORM.

    📝 Описание: Проектирование и реализация backend-части ERP-системы «WoodFlow» для автоматизации складского учета, резервирования (бронирования) и логистики пиломатериалов.

    Цель работы: Архитектурное проектирование многокомпонентного веб-приложения. Освоение принципов работы с реляционными базами данных через ORM, реализация вычисляемых полей и агрегационных SQL-запросов, построение ролевой модели доступа (RBAC) с защитой эндпоинтов, а также интеграция системы с динамическими графиками и модулями выгрузки отчетности в формате Excel.

    Основные задачи: * Разработка реляционной схемы БД (клиенты, пачки, брони, транспортные накладные) и связей между ними. * Реализация калькуляционных алгоритмов (расчет 4 типов объема и веса древесины с учетом усушки и плотности). * Разделение прав доступа на уровне сессий (Администратор / Менеджер склада). * Создание API-эндпоинтов для передачи аналитических данных в формате JSON.

    Стек: Python, Flask, SQLAlchemy, Flask-Login, Flask-WTF, SQLite

    Лабораторная работа №7

    Лабораторная работа: Инструменты для работы с языком

    Тема: Векторизация текстов, предобработка естественного языка (NLP) и анализ тональности.

    📝 Описание: Работа посвящена изучению базовых методов обработки текстов на естественном языке. Основная задача заключается в построении модели машинного обучения для классификации русскоязычных твитов по их эмоциональной окраске (позитивные или негативные). В ходе выполнения исследуются подходы к очистке данных (удаление стоп-слов, токенизация с помощью NLTK, анализ влияния пунктуации), приведению слов к начальной форме (лемматизация через Pymorphy3) и извлечению признаков (модели «мешка слов» CountVectorizer и TF-IDF на базе различных n-грамм). Для решения задачи классификации применяются и сравниваются алгоритмы Logistic Regression, Multinomial Naive Bayes и XGBClassifier.

    Стек: Python, Pandas, Scikit-learn, NLTK, Pymorphy3, XGBoost

    Лабораторная работа №6

    Предобработка данных и EDA с применением Pandas

    Тема: Предобработка и первичный анализ данных (на примере датасета Titanic).

    📝 Описание: Проект посвящен освоению методов подготовки "сырых" данных к анализу и машинному обучению на классическом наборе данных пассажиров Титаника. В ходе работы был проведен полный цикл предобработки: первичный разведочный анализ (EDA), оценка и заполнение пропусков (медианой, модой и константами), а также преобразование типов. Особое внимание уделено генерации новых признаков (Feature Engineering), таких как социальный статус (титулы) и размер семьи, и обработке выбросов с использованием метода Winsorization (ограничение по 95-му перцентилю). В завершение выполнена агрегация данных и визуализация матрицы корреляций, что позволило выявить ключевые факторы выживаемости на борту.

    Стек: Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, EDA

    Лабораторная работа №5

    Регрессия с применением Scikit-Learn и XGBoost

    Тема: Разработка системы прогнозирования стоимости недвижимости с применением алгоритмов машинного обучения.

    📝 Описание: Проект посвящен созданию регрессионной модели для автоматической оценки стоимости жилья в округе Кинг (США) на основе исторических данных о продажах и характеристиках объектов (площадь, геолокация, оценка риелтора и др.). В ходе работы был проведен полный цикл Data Mining: предварительная обработка данных, анализ значимости признаков (Feature Importance) и фильтрация неинформативного шума. Для поиска оптимального решения были обучены и сравнены между собой несколько алгоритмов машинного обучения: Линейная регрессия, Случайный лес (Random Forest) и Градиентный бустинг (XGBoost). Был произведен автоматический подбор гиперпараметров с помощью GridSearchCV на основе кросс-валидации. Оценка качества моделей производилась по метрикам MAE и RMSE. В завершение была спроектирована архитектура развертывания финальной модели в виде REST API веб-сервиса с помощью фреймворка FastAPI.

    Стек: Python, Scikit-Learn, XGBoost, Pandas, NumPy, Jupyter Notebook, Linear Regression, RandomForestRegressor, GridSearchCV, FastAPI, MAE / RMSE

    Лабораторная работа №4

    Классификация с применением Scikit-Learn

    Тема: Разработка системы предиктивного кредитного скоринга и оценки риска дефолта.

    📝 Описание: Проект посвящен созданию модели машинного обучения для автоматического предсказания вероятности возврата кредита банковскими клиентами на основе их исторических и демографических данных. В ходе работы был проведен полный цикл подготовки данных, включая разведочный анализ (EDA), обработку пропусков и кодирование категориальных признаков. Для поиска оптимального решения были обучены, настроены с помощью кросс-валидации и сравнены между собой несколько алгоритмов: от базовых kNN и логистической регрессии до ансамблевых методов (Random Forest, Gradient Boosting). Итоговая оценка качества классификации производилась с использованием матриц ошибок и метрики ROC-AUC, после чего была спроектирована архитектура развертывания финальной модели в виде REST API веб-сервиса.

    Стек: Python, Scikit-Learn, Pandas, NumPy, Jupyter Notebook, Logistic Regression, RandomForest, SVM, kNN, K-Fold Cross-Validation, ROC-AUC

    Лабораторная работа №3

    Автоматизация сборки сайта McDocs

    Тема: Реализация автоматического деплоя статического сайта с использованием нескольких удаленных Git-репозиториев.

    📝 Описание: В ходе выполнения задачи были на практике освоены базовые принципы DevOps-инженерии и с нуля настроен полноценный процесс непрерывной интеграции и доставки (CI/CD).
